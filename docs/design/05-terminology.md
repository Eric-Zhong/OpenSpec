# 05-terminology.md

## OpenSpec CLI 术语表

| 中文术语 | 英文术语 | 说明 |
|----------|----------|------|
| CLI | CLI | 命令行接口（Command Line Interface） |
| 子命令 | Subcommand | CLI 的具体功能模块（如 `init`, `list`） |
| 工具 | Tool | AI 驱动的自动化工具 |
| 遥测 | Telemetry | 用户行为数据采集与分析 |
| 命令驱动 | Command-Driven | 以命令为核心的工作流设计 |
| 模块化架构 | Modular Architecture | 分层模块化的设计模式 |
| 错误处理 | Error Handling | 异常捕获与用户反馈机制 |
| 配置文件 | Config File | 存储用户偏好和系统设置的文件 |
| JSON 格式 | JSON Format | 结构化数据交换格式 |
| 颜色输出 | Color Output | 命令行界面的彩色显示 |
| 强制操作 | Force Operation | 无需用户确认的自动化操作 |
| 依赖关系 | Dependency | 模块之间的调用关系 |
| 执行流程 | Execution Flow | 命令处理的完整生命周期 |
| 术语表 | Terminology | 专业术语的中英文对照表 |

## 术语说明

- **CLI**：Command Line Interface 的缩写，即命令行接口
- **Subcommand**：CLI 的具体功能模块
- **Telemetry**：用户行为数据采集与分析
- **Modular Architecture**：分层模块化的设计模式
- **Error Handling**：异常捕获与用户反馈机制
- **Config File**：存储用户偏好和系统设置的文件
- **JSON Format**：结构化数据交换格式
- **Color Output**：命令行界面的彩色显示
- **Force Operation**：无需用户确认的自动化操作
- **Dependency**：模块之间的调用关系
- **Execution Flow**：命令处理的完整生命周期
- **Terminology**：专业术语的中英文对照表
